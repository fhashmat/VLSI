# Model Synthesis Data v1

This folder contains the intermediate and final outputs produced during synthesis of the VLSI-SWSC attack taxonomy model.

The model combines the normalized software supply-chain attack categories, software-side capabilities, VLSI-side attack classes, design stages, and security outcomes to generate possible attack paths following:

`A_sw -> M_sw -> A_vlsi -> Stage -> Outcome`

## Files

- `Synthesis.csv`  
  Contains the synthesized taxonomy mappings used to construct the model, including the normalized `A_sw`, `M_sw`, and `A_vlsi` relationships derived from the source extraction and bridge-mapping data.

- `model_summary_v1.csv`  
  Contains aggregate statistics for the synthesized model, including the number of model entities, valid relationships, and generated attack paths.

- `synthesized_attack_paths_v1.csv`  
  Contains the complete set of 717 possible attack paths generated by the model. Each path records its `A_sw`, `M_sw`, `A_vlsi`, design stage, and security outcome.

## Output

The synthesis process generates **717 possible VLSI-SWSC attack paths**.

These paths represent model-supported combinations permitted by the encoded taxonomy relationships. They are possible attack paths and are not, by themselves, claims of experimental validation.

The subsequent feasibility analysis in `../feasibility_v1/` evaluates the empirical support for these synthesized paths.
